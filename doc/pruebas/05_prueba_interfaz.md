# Prueba de Interfaz (UI)

Verifican que los componentes visuales funcionen correctamente y que la experiencia de usuario sea la esperada.

| ID | Componente | Acción | Resultado esperado |
|----|-----------|--------|--------------------|
| UI-01 | Botón nav "Vehículos" | Clic | Se muestra PageVehiculos, botón se resalta en naranja |
| UI-02 | Botón nav "Clientes" | Clic | Se muestra PageClientes |
| UI-03 | Botón nav "Alquilar" | Clic | Se muestra PageAlquilar |
| UI-04 | Botón nav "Devolver" | Clic | Se muestra PageDevolver |
| UI-05 | Tabla de vehículos | Cargar datos | Se muestran filas alternadas, encabezados correctos |
| UI-06 | Tabla PageAlquilar | Clic en fila | Se autocompleta el campo PATENTE |
| UI-07 | Tabla PageDevolver | Clic en fila | Se autocompleta el campo PATENTE A DEVOLVER |
| UI-08 | Mensaje de éxito | Acción correcta | Texto en verde |
| UI-09 | Mensaje de error | Acción incorrecta | Texto en rojo |
| UI-10 | Campos de formulario | Submit vacío | Mensaje de error visible, no se procesa |
| UI-11 | Ventana principal | Redimensionar | Los paneles se adaptan correctamente |
| UI-12 | Header | Siempre visible | "AutoRent" visible en todas las páginas |
